# Public-source competitor scan: well planning and operations

**Status: PARTIAL / NOT_MEASURED.** This is a scoped review of public vendor descriptions, not hands-on testing, an independent benchmark, an exhaustive market survey, a ranking, or proof that any advertised feature works as claimed. Sources are first-party marketing/product materials retrieved during this mission; their page content can change. No vendor source code or interface was copied. Commercial terms, access conditions, performance, accuracy, security certifications, interoperability and customer outcomes were not independently verified.

## Interpretation and next evidence

These sources help identify possible user needs, not whether either product is superior. Vendor claims of validation, market share, time savings, safety, or customer outcomes were not adopted as measured facts. The DrillAI-side comparison is limited to identified source and existing synthetic/software tests; no independent apples-to-apples data, calculation reference set, paid product access, real customer workflow or field benchmark was available. The next useful study is a controlled, non-confidential reference set with identical explicit inputs, units, assumptions, expected outputs and tolerances, followed separately by authorized human-reviewed workflow and field assessments. A failed or missing metric must remain visible rather than converted into a marketing comparison.
