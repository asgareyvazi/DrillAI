# Picomatch advisory: upstream remediation status

**Status: NOT_ACCEPTED.** The full dependency audit remains blocked by [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). At this inspection the GitHub advisory API reported the vulnerable range `<=4.0.7` and no first patched version; `npm view picomatch version` returned `4.0.7`. The mission clock and external GitHub metadata differ: the API reported update timestamps in November 2026, later than the mission date, so those timestamps are source metadata rather than an independently verified current date.

Public upstream issue [#247](https://github.com/micromatch/picomatch/issues/247) requests fix/release guidance. A search found multiple open, competing proposals, including [#262](https://github.com/micromatch/picomatch/pull/262) against master and [#263](https://github.com/micromatch/picomatch/pull/263) against v2. At inspection their heads were respectively `3222059ac27492d9c0147fee5c65f751bbd851ab` and `9ca61909ab0ec680953e21bac80a6e825e1ede81`, and neither was merged. Their descriptions claim bounded adversarial and compatibility testing, but this mission did not independently run or verify those results. [#272](https://github.com/micromatch/picomatch/pull/272) describes a more conservative fallback with changed matching semantics. These are candidate approaches, not accepted fixes, published versions, advisory clearance or a proof of safety. A v2 proposal's description also reports a failing upstream `npm test` lint stage alongside passing other tests; that is an upstream author statement, not a DrillAI test result.

No unreviewed fork, forced downgrade, patched-version relabeling or audit suppression was introduced. The 2.x and 4.x dependency paths both need compatible upstream releases (or separately reviewed replacement and independent security/compatibility validation) before the complete audit can pass. Production-only audit results do not substitute for the full dependency gate. Recheck the advisory, both release lines, lockfile resolution, full test suite and exact-SHA CI when an upstream remedy is available.
