## NPT interval blocker evidence

The NPT reconciliation now reports a first-failing reason and the event, source-document and source-record IDs for each invalid event, including unknown-time events that the legacy time-filtered list omits. Reason counts cover the evaluated non-temporal scope, while the detail list is deterministically ordered by event ID, capped at 100 and explicitly marked when truncated. When the 10,000-event processing limit is exceeded, blocker counts and details are unavailable rather than a misleading partial result. Outside-window rows do not block the window. The API retains its separate legacy row sums, interval union and overlap; it does not infer causes, merge identities, allocate overlap, change raw values, approve evidence, or claim physical downtime completeness. The first reason is not an exhaustive defect list. ## OCR publication guard

A successful child that has already exited can return from `wait(timeout=0)` after the shared deadline, and pipe teardown or TSV parsing can finish after that deadline. The adapter now fails closed instead of publishing recognition lines after expiration, including after final ordering. Focused tests cover late successful spawn, late parsing and a late route; 28 OCR tests and Ruff passed. This is not an interruptible hard end-to-end deadline: layout, PDF parsing/rasterization, process startup and cleanup may still block; Windows process-tree containment is still missing and escaped POSIX sessions are not contained. No corpus, scorer, segmentation, model or language route was changed, and no OCR quality improvement is claimed.
