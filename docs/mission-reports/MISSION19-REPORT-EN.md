- **Programs and Procedures — PARTIAL.** The Mission 18 validation, withdrawal and preserved history flow has a new deterministic SQLite competing review/withdrawal test: the former lost review now causes a conflict, and a retry preserves history. A competing PostgreSQL HTTP transaction/lock regression, rollback checks and isolated synthetic two-well browser/SQLite readback passed. The first complete PostgreSQL suite then exposed test-schema contamination causing two downstream failures; the concurrency test now uses a separate disposable server, and the three-test sequence passed. See [isolation evidence](mission19-evidence/postgres-test-isolation.md). This is not a complete concurrency proof or field pilot; broader product and engineering acceptance remains open.
- **OCR — NOT_ACCEPTED.** Adapter v12 rejects malformed text-bearing word evidence instead of silently discarding it and publishing partial text. PDF ingestion tests verify failed-page behavior. The unchanged frozen corpus SHA-256 is `31aca80b4323fe470d34705e36038296ef620adb7525373f5196c9f561b6735d`. Local Tesseract 5.5.4/tesserocr emulation evaluated all 64 synthetic cases and failed with 311/384 critical fields, CER 1638/15305 and WER 360/2328, unchanged by the safety change. It is not the deployment CLI/image. - **Connector and notification egress — PARTIAL.** A fail-first DNS interleaving showed that a more permissive global policy could be applied during a lookup begun under a restrictive one. The resolver now requires the same DNS answers to satisfy the entry and current policies; tests cover widening, revocation, normal resolution, and a webhook path where no HTTP client is created after denial. This does not provide application/database ownership of global state or stop changes after pinning; see [race evidence](mission19-evidence/egress-dns-race.md).
