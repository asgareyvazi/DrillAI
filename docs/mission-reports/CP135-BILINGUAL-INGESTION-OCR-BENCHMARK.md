# CP135 — Bilingual ingestion OCR benchmark

**Status:** CP135 is **not accepted**. Exact-SHA run **42728606694** evaluated all 64 v2 cases with PSM 3 and the required Tesseract/PDFium/English/Persian components, but failed globally (CER **0.399696**, WER **0.496546**, critical-field exact rate **0.419271**) and in every stratum. On the same v2 corpus/runtime, this is worse than the previous PSM 6 run **42725631378** (CER **0.262858**, WER **0.370898**, critical exact **0.583333**); PSM 3 is not accepted as a fix. All 64 transcript-free per-case rows were recovered from run 427286's bounded check annotations and saved at `docs/mission-reports/CP135-RUN-42728606694-CASE-EVIDENCE.json`; the artifact-download endpoint still returns `EOF`. A balanced v3 full-factorial corpus is now in the worktree for the next exact-SHA measurement. Run 427286's Windows job also failed one existing timestamp-provenance test, so this run is not cross-platform certification. Thresholds remain unchanged; no OCR pass, field accuracy, or operational readiness is claimed.

## Scope implemented

- Added the historical v2 deterministic, versioned 64-case image-only DDR corpus at `backend/src/drillai/ingestion/data/synthetic_ddr_ocr_quality_v2.json`, generated by `scripts/generate_synthetic_ocr_quality_corpus.py`; its SHA-256 is `c0c4bdbae9e191d9b62a649f31bb44201337bf24a663f9c91525f246205bdbe0`.
- Added v3 corpus `backend/src/drillai/ingestion/data/synthetic_ddr_ocr_quality_v3.json`, SHA-256 `31aca80b4323fe470d34705e36038296ef620adb7525373f5196c9f561b6735d`: a balanced full factorial of 2 languages × 4 layouts × 4 scan conditions × 2 distinct value sets per cell. It has 32 English, 32 Persian, 16 cases per layout and scan stratum, and exactly 2 cases in every language/layout/scan cell, including 8 Persian two-column cases. The v2 corpus is retained to preserve historical run reproducibility.
- Both corpora cover the four page layouts (`single_column`, `table`, `two_column`, `compact`) and controlled scan conditions (`clean`, `low_contrast`, `light_skew`, `light_noise`). Every case has a unique ID, explicit synthetic critical-field values, language/layout/scan strata, and an image-only generated PDF digest in measured evidence.
- The runner sends each generated PDF through the production `parse_bytes` path and the configured PDFium/Tesseract adapters. Persian cases are run only when both `eng` and `fas` are configured and installed. Missing language data, Tesseract, PDFium, rendering dependencies, incomplete page processing, or any metric failure yields a non-passing report/exit status; there is no fallback to fixture text in the deployment-image gate.
- Global and per-stratum metrics are micro-aggregated from per-case error counts and denominators. The reviewed software thresholds are CER ≤ 0.15, WER ≤ 0.20, and critical-field exact rate ≥ 0.90, required globally and in every reported language, layout, and scan-condition stratum. The report records Python, Tesseract, PDFium, image/RTL renderer dependency versions, configured/available languages, and OCR resource limits. The verifier recomputes global and stratum totals from per-case evidence, checks the corpus digest/runtime languages, and rejects transcript/path material.
- CI runs the CP135 corpus inside the backend deployment image. The prior CP132 32-case English result remains a historical result for its original corpus/SHA; it is not presented as CP135 evidence.
