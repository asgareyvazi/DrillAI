## Engineering changes

* `wellbore.capacity` 1.3.0 refuses missing outer bore over the full model or to the current bit, unknown inner-string ID, overlapping inner strings, incompatible nested bores, and missing string intervals unless the caller explicitly declares `verified_open_bore`. That flag is a caller assertion, not verification by DrillAI. Volume calculations still assume nominal, concentric geometry, not tool joints or field conditions. This is not a completed capacity/circulation vertical slice.
* `hydraulics.laminar` 1.4.0 requires an explicit positive bit TVD not exceeding bit MD; it no longer substitutes MD. It requires a complete, unambiguous inner-string and annular geometry from surface to bit. Synthetic vertical-well examples explicitly specify TVD; the optimisation page labels the example and asks the user to replace it. The slot approximation, laminar limitation, optimistic non-certified turbulent warnings, omitted surface/BHA losses and missing TFA warning remain. A user-supplied TVD is not independently verified; no field acceptance or accurate turbulent ECD is claimed.
* The pre-fix focused regressions for the four capacity geometry cases plus explicit bare bore failed 5/5; three incomplete hydraulics paths also failed to be rejected. After the changes the focused engine/API/adversarial run passed 261 tests locally. It includes API refusal and persistence coverage; it is not an independent comprehensive audit of all 14 engines. Previous independent synthetic reference cases still pass in that selection.
* The roadmap engine table is now generated by `scripts/verify_engine_roadmap.py` from the runtime registry; both CI platforms check drift. SHA-256 hashes identify LF-normalized source files (CRLF checkouts normalize to LF), and status is a **registry self-declaration**, not an independent assessment. Guard tests exercise altered version and malformed markers. The reviewed backend inventory adds nine cases (1,846 total, 15 PostgreSQL-only); platform pass counts are manifest expectations until observed.
