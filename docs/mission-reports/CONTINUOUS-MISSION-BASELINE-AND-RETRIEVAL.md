## Scoped Persian lexical retrieval

Source inspection identified an ASCII-only lexical tokenizer: Persian-only queries had no tokens and could fall back to newest-first metadata results rather than actual lexical matches. `backend/src/drillai/rag/retriever.py` now supports Unicode word tokens, Persian/Arabic yeh and kaf variants, Persian/Arabic digit normalization and Persian half-space as a token boundary. The original stored source text, page locator and citation identifiers are returned unchanged. This is deterministic lexical matching, not translation, semantic embeddings, independently measured retrieval quality, or a guarantee of matching every Persian spelling/inflection. The existing candidate bounds, well/section/tenant filters and no-token-match behavior remain in force.

`backend/src/drillai/ai/tools.py` now passes the authenticated tool context's project and operation scope to retrieval. Previously those fields were omitted, so project-only searches failed and a conflicting project/well or operation context could be widened. The tool still enforces its existing permission and audit gateway; missing operation attribution does not become a match.

Three new tests in `backend/tests/rag/test_retriever.py` exercise normalization and unchanged English identifiers; real persisted chunks, scoped Persian/mixed search, unchanged source and citations, no-match and explicitly labelled lexical fallback; and authorized/audited `search_documents` invocation with project-only, conflicting project/well and operation scopes. The reviewed manifest and README expectations increase by exactly three tests. Focused RAG/AI/workflow/CI-contract/README-guard selection passed **112**; a separate original RAG benchmark selection passed within a **67** test run. The full local SQLite backend suite then passed **1,784 with 15 reviewed PostgreSQL-only skips**, and the default inventory verifier passed; this is not PostgreSQL-enabled or native-Windows evidence. Existing English synthetic benchmark is not a Persian holdout benchmark, and authentic semantic/hybrid retrieval is not claimed measured by this change.
