# Pinned Persian Tesseract model

`fas.traineddata` is the Persian model from the official [`tesseract-ocr/tessdata_fast`](https://github.com/tesseract-ocr/tessdata_fast) repository at commit `87416418657359cb625c412a48b6e1d6d41c29bd`.

- Repository license: Apache License 2.0; the corresponding license text is in `LICENSE`.
- The model is pinned to make the OCR deployment dependency reproducible. Pinning the model is not a quality acceptance claim. The unchanged CP135 thresholds and all corpus strata remain required.
